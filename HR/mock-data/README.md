# 模拟数据包

全部数据为虚构，用于工作坊方法演练。不得用于任何真实结论。

## 文件清单

| 文件 | 关键字段 | 用法 |
|---|---|---|
| crm-accounts.csv | 客户编号、等级、年度采购额、最近拜访日期、最近订单日期、应收账款 | 客户主数据，40 家 |
| crm-visits.csv | 客户编号、拜访日期、关键人角色、客户原话摘要、异议、下一步 | 拜访记录，200 条，含 3 条孤儿记录 |
| crm-opportunities.csv | 客户编号、阶段、金额、赢率、停滞天数 | 商机，60 条 |
| talent-review.csv | 绩效、潜力、任职年限、关键岗位、继任者就绪度 | 九宫格，60 人 |
| attrition-risk.csv | 绩效、薪酬分位、距上次晋升年限、岗位稀缺度 | 离职风险因子，50 人 |
| employee-voice.csv | 部门、司龄段、反馈原文 | 开放题，200 条 |
| recruiting-funnel.csv | 周次、渠道、投递到入职各环节、渠道成本 | 12 周 6 渠道，72 行 |
| hr-tickets.csv | 主题、问题描述、处理方式、状态、处理时长 | 共享服务工单，120 条 |
| interview-panel.csv | 候选人、面试轮次、正面观察、顾虑、个人结论 | 2 人各 4 轮 |
| policy-handbook.md | 第 12 到 48 条 | 员工手册节选，内埋 8 处风险条款 |

## 刻意埋的问题

- crm-visits.csv 中 V0031、V0065、V0119 三条记录的客户编号在主数据里不存在。用来说明关联前必须查数据质量。
- policy-handbook.md 中第 12、15、21、26、33、38、42、48 条存在法律风险，用于合规体检场景。
- employee-voice.csv 有 23 条无信息量的正向反馈，占 11.5%，用于检验聚类是否会丢数据。
- talent-review.csv 中"高高"仅 3 人，"中中"16 人，符合真实分布，避免学员误以为高潜遍地。

## 重新生成

```bash
python3 generate_mock_data.py
```
